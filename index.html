시작하기

내 주변 스포츠, 오운디 — 소개 영상

시작하기
  1. 운동할 곳, 이제 한 번에 찾아요. 인천 연수구(송도 포함)에서 먼저 시작해요.
  2. 공공·민간 시설을 한 화면에. 체육관, 수영장, 테니스장, 클라이밍장까지 모아 보여드려요.
  3. 말하듯 찾으면 돼요. 한마디가 지역·종목·주차 같은 조건으로 바뀌어요. (시연 화면)
  4. 가까운 곳부터 좁혀 봐요. 거리, 종목, 공공·민간 여부로 골라요. (시연 컨트롤)
  5. 어디서 온 정보인지도 함께 보여요. 기관 자료인지, 실시간 정보인지 분명히 적어 둬요.
  6. 필요한 것만 한눈에. 이름·위치·종목·출처를 한 화면에 모았어요.
  7. 예약은 시설마다 길이 달라요. 공공시설은 기관 공식 예약 페이지로 안내해요. 이동만으로 예약이 끝나진 않아요.
  8. 고르고, 확인하고, 출발. 지역, 종목, 시설 정보, 예약 경로 순서예요. 지도는 카카오맵 연동을 준비 중이에요.
  9. 찾는 시간은 짧게, 운동하는 시간은 길게.
  10. 이제 시작해 볼까요? 웹과 앱으로 곧 만나요.

지금 만들고 있는 앱 화면

시연 화면 개발 중인 오운디 앱을 테스트용 가상 데이터로 캡처했어요.

오운디의 지도 활용 목적

연결 예정 카카오맵 연동을 준비 중입니다.

  1. 1
    시설을 지도에 표시운동 시설 위치를 핀으로 보여드려요.
  2. 2
    연수구 주변 보기연수구·송도와 그 주변을 한눈에 봐요.
  3. 3
    주소를 좌표로허용되는 범위에서 주소를 좌표로 바꿔 지도에 올려요.
  4. 4
    장소 검색시설 이름이나 장소로 찾아요.
  5. 5
    다음 단계 고르기위치를 보고 방문할지, 예약할지 정해요.
지도 서비스로지도 표시와 장소 검색
각 기관 자료로공공시설 예약 정보와 공식 예약 페이지

이 페이지는 지도 API 승인을 보장하지 않으며, 지도 서비스와의 제휴를 뜻하지 않아요.

지금 어디까지 왔냐면요

보기 좋게 꾸미기보다 솔직하게 적었어요.

  • 시연 화면말로 찾는 검색개발용 데이터·규칙으로 동작
  • 개발 중공공·민간 함께 보기테스트용 가상 데이터로 확인, 실제 공공 데이터 연결 전
  • 개발 중출처·확인 시각 표시시설마다 자료 출처를 함께
  • 개발 중기관 예약 페이지 안내이동만으로 예약 완료 아님
  • 시연 화면앱 안 예약테스트 결제만, 실제 결제 없음
  • 연결 예정지도(카카오맵)지금은 간이 지도
  • 연결 예정로그인(Firebase)지금은 개발용 로그인
  • 연결 예정앱 출시앱스토어·구글 플레이에 아직 없어요

공개 문의처는 정해지면 여기에 적어 둘게요.
